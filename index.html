01

Problem Description

🏠

Room Setup

A room containing three key objects: a monkey, a movable box, and a banana suspended from the ceiling — out of the monkey's direct reach unless it climbs on the box.

📍

Initial State

Monkey at position A on the floor.
Box at position B, movable.
Banana hanging at position C — out of reach.

🎯

Objective

Find an optimal sequence of operators — Move, Push, Climb, Grab — that transitions the system from the initial state to the goal state where the monkey is holding the banana. This models how an intelligent agent must reason about multi-step consequences before acting.

02

Operator Sequence

01
Action · Move

Walk to the Box

The monkey moves from its initial position A toward position B where the box is located. This positions the monkey adjacent to the box so it can be manipulated.

→
02
Action · Push

Push Box Under Banana

The monkey pushes the box from position B to position C, aligning the box directly beneath the suspended banana. The monkey's position updates accordingly.

→
03
Action · Climb

Ascend the Box

The monkey climbs onto the top of the box at position C. This increases the monkey's effective reach height, making the banana reachable for the first time.

→
04
Action · Grab · Goal State

Grab the Banana 🍌

The monkey grasps the banana. The goal state is reached: monkey holds banana = true. The planning problem is solved in the minimum number of steps.

06

Agent Architecture

Goal-Based
Reflex Agent

Unlike simple reflex agents that react purely to current percepts, a goal-based agent uses knowledge of the environment and a desired end-state to plan a sequence of actions that achieves the goal.

In this problem, the agent evaluates consequences before committing to any action, selecting only those operators that progress it toward the goal state.

  • Holds an internal model of the environment and object states
  • Plans sequences: Move → Push → Climb → Grab
  • More intelligent than simple reflex — considers consequences
  • Operates in a fully observable, deterministic environment

07

Search Algorithms

Recommended
BFS
Breadth-First Search

Systematically explores states by increasing depth. In a discrete, finite state space, BFS guarantees the shortest action sequence when every action has equal cost.

Optimal Complete Memory: O(b^d)
DFS
Depth-First Search

Explores deep paths first. Can find a solution quickly, but may return a non-optimal sequence and can get stuck in long branches without careful cycle detection.

Non-optimal Low memory Needs cycle check
UCS
Uniform-Cost Search

Generalises BFS by expanding the lowest-cost node first. Optimal when actions carry different costs — reduces to BFS when all costs are equal.

Optimal Cost-sensitive
A*
A* Search

Uses an admissible heuristic (e.g. Manhattan distance to align box under banana) to guide search. Most efficient when a good heuristic is available.

Optimal Heuristic-guided Heuristic design

Practical note: Use state hashing to avoid revisiting states and prevent loops. For non-uniform action costs, prefer UCS or A* with an admissible heuristic such as Manhattan distance to align the box beneath the banana.
